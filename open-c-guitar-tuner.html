What is Open C tuning?

This version of Open C uses C G C G C E. The open strings contain only C, E, and G—the notes of a C major chord. Open C can produce a wide range and strong low drones, but the low sixth string moves far below standard pitch.

How to tune from standard

  1. Lower the sixth string from E2 to C2.
  2. Lower the fifth string from A2 to G2.
  3. Lower the fourth string from D3 to C3.
  4. Leave the third string at G3.
  5. Raise the second string carefully from B3 to C4.
  6. Leave the first string at E4, then recheck all strings.
Important: The second string tunes upward by one semitone while the low strings tune down. Approach C4 slowly and do not overtighten.

Playing in Open C

The open position is C major. A full barre moves that major shape up the neck, while open C and G strings can ring beneath melodies. Standard-tuning chord shapes do not transfer directly, so use diagrams specifically written for C G C G C E.

Setup considerations

The sixth string may feel very loose at C2 on a light set. A heavier low string can improve definition, but large gauge changes may require nut and intonation work. Because Open C tunings vary, always confirm the exact string sequence before using a lesson or chord chart.
