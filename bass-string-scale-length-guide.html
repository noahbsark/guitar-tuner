Bass String Scale Length Guide

Measure the installed string path before buying a replacement set. Two basses with the same scale length can need different winding lengths.

Published by Online Guitar Tuner. How our guides are maintained · Report a correction

Measure the string path

The instrument’s scale length describes the vibrating part of the string. It runs from the nut to the saddle, with small saddle adjustments for intonation. For replacement fit, you need the longer distance from the ball end’s seat to the headstock side of the nut.

  1. Check whether your strings anchor at the bridge or pass through the body. If the bass accepts both, measure the route you plan to use.
  2. On a top-loading bridge, follow the lowest string from where it leaves the seated ball end, over the saddle, to the headstock side of the nut. Exclude the ball itself.
  3. If the anchor is hidden in the body, mark the installed string at the headstock side of the nut, slacken and remove it, then measure from the string side of the ball to your mark.
  4. Check how far the first tuning post sits beyond the nut. Follow the string maker’s taper placement instructions and confirm there is enough length to reach and wind onto the post. On a multiscale or unusual bridge, check the path for each string.

Compare the manufacturer’s winding lengths

D’Addario publishes these distances from the ball end to the start of the taper. Use the chart for the exact brand and set you’re considering.

If your measured path is 31½ inches, the 32-inch taper starts about ½ inch past the nut. If the path is 35 inches, the 36⅞-inch taper starts 1⅞ inches past it. In both cases, confirm where that falls relative to the post before buying. A set that tapers before the nut is too short for this fit method.

Check the rest of the fit before ordering

  • String count and tuning. A five-string low-B set and a high-C set give you different notes and gauges. Match the tuning your bass is set up for.
  • Gauge and construction. If your current set feels right, match its gauge and winding type. Replacing one worn or broken string can be enough when its match is available and the others are fresh.
  • Bridge mounting. Confirm that the exact set supports your string route. For a through-body bridge or headless bass, use the instrument and string makers’ fit guidance.
