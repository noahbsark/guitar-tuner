Nashville Guitar Tuning Guide

Nashville tuning uses the octave strings from a 12-string-style set to create a bright, chiming six-string sound.

What is Nashville tuning?

Nashville tuning, also called high-strung tuning, keeps the familiar E A D G B E note names but raises the lowest four courses by one octave. From the sixth string to the first, the pitches are E3 A3 D4 G4 B3 E4. The B and high E strings stay at their normal standard-tuning octaves.

Do not tune a normal six-string set this way. Standard low E, A, D, and G strings are too heavy to raise an octave safely. Use a purpose-made Nashville set or the correct octave strings from a 12-string set.

How to set it up

  1. Buy a Nashville/high-strung set or select the octave strings intended for a 12-string guitar.
  2. Install one string at a time and confirm its intended pitch before adding tension.
  3. Bring each string up gradually, then stretch it gently.
  4. Tune through all six strings several times while the new set settles.

Why players use it

The tuning preserves standard chord fingerings while removing the heavy bass register. Double-tracking a normal guitar with a Nashville-tuned guitar creates a wide, 12-string-like shimmer while allowing each performance to be panned or processed separately. It also works well for bright arpeggios and layered acoustic arrangements.

Setup considerations

The much lighter bass-side strings may change neck relief, nut fit, intonation, and pickup balance. A guitar dedicated to Nashville tuning can benefit from a setup for the lighter gauges. If the instrument will switch back and forth, expect to retune and recheck its setup.
