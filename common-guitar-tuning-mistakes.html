Common Guitar Tuning Mistakes

If your tuner looks correct but the guitar still sounds wrong, one of these simple mistakes is often responsible.

1. Tuning the wrong string or tuning key

Before turning anything, pluck one string and trace it visually to its tuning post. Beginners sometimes watch the tuner display for one string while adjusting another. Make only a small turn, then pluck again to confirm the pitch moved in the expected direction.

2. Aiming for the right letter in the wrong octave

A chromatic tuner can show the correct note name even when a string is far too low or dangerously high. Standard tuning is E2, A2, D3, G3, B3, and E4 from the thickest string to the thinnest. Use the guitar string frequency chart when the pitch sounds unusually loose or tight.

Safety: If a string feels extremely tight, stop. Do not keep raising it merely because the display shows the expected letter.

3. Plucking too hard

A hard attack briefly stretches a string sharp, especially a low or detuned string. Pluck with the moderate force you normally use, wait for the initial pitch spike to settle, and tune during the stable portion of the note.

4. Letting other strings ring

Open strings can vibrate sympathetically and microphones can hear nearby sounds. Mute the other five strings, face the instrument toward the microphone, and tune in a quiet room. For rehearsals or loud spaces, a vibration-based tuner may work better; see the clip-on versus online tuner comparison.

5. Making large tuning-key movements

Near the target pitch, use tiny adjustments and pluck after each one. Large turns cause you to overshoot repeatedly. If you go sharp, lower the pitch slightly below the target and tune upward again.

6. Forgetting to tune upward to the note

Approaching pitch from below helps settle slack in the string path. If you finish by loosening down to the note, slack at the nut or tuning post can release later and make the string go flat. Lower it a little farther, then tighten gradually to the target.

7. Using old or poorly installed strings

Corroded, flattened, or kinked strings may tune open but sound inconsistent across the neck. New strings can also drift until their wraps settle. Read why new strings go out of tune and check the installation before adjusting guitar hardware.

8. Tuning only once

Changing string tension can slightly affect the neck or a floating bridge. Tune all six strings, then repeat the sequence until each remains stable. With a floating tremolo, several passes are normal.

9. Confusing tuning with intonation

If open strings are correct but fretted chords sound increasingly wrong higher on the neck, repeated open-string tuning will not solve the problem. Check the 12th-fret note and read the intonation guide.

10. Selecting the wrong tuning or reference pitch

Confirm the tuner preset before starting. Standard, Drop D, half-step down, 432 Hz, and 528 Hz reference tuning have different targets. For ordinary standard tuning, select Standard — E A D G B E with the normal A=440 reference.

A reliable routine

  1. Select the intended tuning.
  2. Mute unused strings and pluck moderately.
  3. Identify the string before moving its key.
  4. Approach each target from below.
  5. Repeat all six strings once more.
  6. Test a few familiar chords.
