How to Tune a 12-String Guitar

A 12-string guitar has six paired courses: the four lower courses use octave pairs, while the B and high E courses are tuned in unison.

Standard 12-string tuning

A standard 12-string guitar follows the same six note names as a six-string guitar: E A D G B E. Each note is doubled to form a course. The four lower courses—E, A, D, and G—combine a normal string with a thinner string tuned one octave higher. The B and high E courses use two strings at the same pitch.

Taylor’s 12-string guidance likewise describes the lower four courses as octave pairs and the B and high E pairs as unisons. String order within each course can differ by manufacturer, so identify the thicker and thinner string rather than relying only on its physical position.

A safe tuning order

  1. Confirm that the strings are installed in the correct courses.
  2. Tune the six thicker or main strings to E2, A2, D3, G3, B3, and E4.
  3. Tune the thin octave E string to E3.
  4. Tune the thin octave A string to A3.
  5. Tune the thin octave D string to D4.
  6. Tune the thin octave G string to G4.
  7. Match the remaining B and high E strings in unison.
  8. Repeat every course because the total tension changes while tuning.
Be especially careful with the octave G string. It is thin and tuned high. Raise it gradually, confirm the octave, and stop if tension feels abnormal.

How to use a chromatic tuner

Mute the other eleven strings and pluck one string at a time. A tuner may display only the note letter, so listen to the register and use the octave table above. This site’s microphone tuner can check the six main-string pitches with the Standard preset, but it is not a twelve-course display. Use a chromatic tuner that identifies the correct octave or enter the octave-string frequencies separately for E3, A3, D4, and G4.

Why the pairs sound slightly animated

Two strings in a unison or octave pair create a broad, shimmering sound. If they are nearly matched but not exact, audible beating becomes faster. Make small corrections until the pulses slow. A perfectly static display is less important than a stable, musical pair.

Should you tune down?

Some 12-string owners tune every course down a whole step to D G C F A D and place a capo at the second fret for standard concert pitch. This reduces open-string tension, but it is not automatically correct for every instrument or string set. Follow the guitar manufacturer’s recommendations and do not assume an older or structurally compromised instrument can safely carry standard tension.

New strings and tuning stability

Twelve fresh strings create many wraps and seating points that must settle. Install neat windings, tune gradually, gently settle each string, and repeat the entire sequence. Read why new strings go out of tune before stretching thin octave strings.

Common 12-string tuning mistakes

  • Tuning an octave string to the lower octave, leaving it floppy
  • Raising a main string to the octave pitch, creating dangerous tension
  • Assuming every pair is tuned in octaves
  • Plucking both strings while the tuner alternates between their pitches
  • Skipping the second tuning pass after total tension changes
  • Using a mismatched replacement string instead of the intended gauge

When the guitar still sounds wrong

Check each string separately, then compare each course as a pair. If open strings are correct but upper chords sound sour, worn strings or intonation may be responsible. A course that repeatedly falls flat may have poor winding, nut binding, or a tuning-machine problem.
