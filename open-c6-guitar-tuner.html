What is Open C6 tuning?

Tune to C A C G C E for an open C6 chord with a warm major sound and an added A. The notes below are listed from the thick sixth string to the thin first string.

How to tune from standard

  1. Lower the sixth string from E2 to C2.
  2. Leave the fifth string at A2.
  3. Lower the fourth string from D3 to C3.
  4. Leave the third string at G3.
  5. Raise the second string from B3 to C4 carefully.
  6. Leave the first string at E4, then recheck every string.
String-safety note: Only the second string rises, by one semitone. Approach C4 from below and stop if the string feels unusually tight; the low sixth and fourth strings will feel looser.

How it feels and sounds

The open chord contains C, E, G, and A, giving it both a C-major foundation and a mellow sixth color. It works especially well for fingerstyle, lap-style ideas, melodic drones, and arrangements that alternate between major and minor colors.

Setup and tuning stability

The lowered sixth and fourth strings may benefit from slightly heavier gauges, while the second string needs only a careful semitone increase. Open C6 has multiple published variants, so always match a lesson to the exact C A C G C E sequence used here.

Practical tuning routine

Tune slowly, use a light attack, and make the final adjustment by approaching each pitch from below. After all six strings are close, repeat the pass because changing one string changes neck and bridge tension slightly. Check again after a minute of playing.
