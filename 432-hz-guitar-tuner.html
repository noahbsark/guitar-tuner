What does 432 Hz tuning mean?

This page keeps standard guitar intervals—E A D G B E—but calibrates the reference note A4 to 432 Hz instead of the widely used 440 Hz. Every target pitch is scaled by 432 ÷ 440, so the guitar remains internally in tune while sounding about 31.8 cents lower than standard concert calibration.

How to tune a guitar to A4 = 432 Hz

  1. Select the 432 Hz preset and allow microphone access.
  2. Pluck one string at a time, beginning with the low E.
  3. Loosen each string gradually because every target is below its 440 Hz equivalent.
  4. Center the meter for all six strings, then repeat the sequence once.

Playing with other musicians

A guitar calibrated to 432 Hz will sound slightly flat beside an instrument calibrated to A4 = 440 Hz. Agree on one reference before rehearsing or recording. If a fixed-pitch instrument cannot be recalibrated, use its reference rather than mixing standards.

What 432 Hz does not change

The tuning is still standard E A D G B E, and chord shapes, scale patterns, and intervals are unchanged. Only the absolute reference pitch moves. Claims that 432 Hz provides medical or healing effects are not established by this tuner; this page is simply a precise pitch-calibration tool.
