Drop B vs B Standard Tuning

Both reach B1, but Drop B creates a dropped-power-chord layout.

Published by Online Guitar Tuner. How our guides are maintained · Report a correction

Quick answer: Drop B is B F# B E G# C#; B Standard is B E A D F# B. Drop B favors one-finger power chords, while B Standard retains standard interval relationships.

At-a-glance comparison

FeatureDrop BB Standard
NotesB F# B E G# C#B E A D F# B
Upper stringsC# Standard patternStandard pattern
Typical useDropped riffsBaritone-style playing

Different fretboards

Drop B derives from C# Standard by lowering string 6. B Standard lowers all standard strings by a perfect fourth. The same fret shape therefore produces different intervals in the two tunings.

Tension and scale

B1 is low for a conventional six-string. Both benefit from heavier strings, while B Standard is especially common on baritone scales. Drop B needs careful balance between the low sixth string and the upper set.

Setup needs

Large gauge changes can affect nut fit, neck relief, action, intonation, and pickup clearance. Do not force a thick string into a narrow nut slot.

How to choose

  1. Choose Drop B for a movable low power-chord barre.
  2. Choose B Standard for familiar scale and chord geometry.
  3. Prefer adequate scale length and a professional setup for permanent use.

Check the interval layout before learning a riff

The shared low B does not make the fretboards interchangeable. In Drop B, the sixth string sits a whole step below the fifth-string pattern, so a straight barre across the lowest strings forms a power chord. In B Standard, all adjacent-string relationships follow standard tuning transposed downward. Confirm which layout the song expects before copying fret numbers, especially when a lesson lists only the lowest pitch.
