What is Drop B tuning?

Drop B uses B F# B E G# C# from the sixth string to the first. It is C# standard with the lowest string dropped one whole step, preserving familiar interval shapes across the upper five strings while creating a low B root.

How to tune from standard

  1. Lower the sixth string from E2 to B1.
  2. Lower the fifth string from A2 to F#2.
  3. Lower the fourth string from D3 to B2.
  4. Lower the third string from G3 to E3.
  5. Lower the second string from B3 to G#3.
  6. Lower the first string from E4 to C#4, then repeat the tuning pass.
Setup note: Every string is lowered substantially. A normal light set will usually feel loose, so use appropriate heavier strings and have the guitar checked after a permanent change.

Sound and playing approach

The lowest three strings form B–F#–B, so barring them at one fret creates a power chord. The upper strings retain the relationships of C# standard, making the tuning useful for metal rhythm parts, low pedal tones, and chord voicings with a clear high register.

String gauges and setup

Many 25.5-inch guitars use roughly .012–.060 or heavier for Drop B, but scale length, playing attack, and preferred tension matter. Gauge changes may require nut-slot, neck-relief, action, and intonation adjustments.

How to get a stable reading

Use the neck pickup if your guitar has one, reduce background noise, and pluck one string gently near its center. Let the pitch settle before adjusting. Tune upward into each target pitch, then repeat all six strings because the neck and bridge respond as total tension changes.
