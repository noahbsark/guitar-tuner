Guitar Tuning Troubleshooter

Pick what you notice to find the first thing to check.

  • The tuner hears nothing
  • The tuner shows the wrong note or jumps
  • One string slips or pings
  • Several strings drift together
  • Open strings are in tune but chords sound wrong
  • The guitar feels too loose or tight after retuning
  • Room noise overwhelms the tuner

The tuner hears nothing

If the tuner is listening but the meter stays still, check Microphone input under the Start listening button. Choose an available device and restart listening.

Check first. Try the input meter before touching a peg. If the browser denied microphone access, open this site’s permission settings. If permission is allowed and the meter stays still, check the selected input, then pluck close to it.

If it continues. When the input meter moves but the note jumps, use the next check.

Microphone help · Tune by ear without granting access

The tuner shows the wrong note or jumps

Check first. Mute every other string, choose the correct preset and pluck moderately. Read the detected note and octave as well as the target. For an unlisted pitch, switch to the chromatic tuner.

If it continues. If the display is steady but the guitar drifts after tuning, check which strings move.

Wrong-note guide · Open the chromatic tuner

One string slips or pings

Check first. Tune it, play normally, and recheck. A string that drops repeatedly may be slipping at its winding or bridge attachment. A ping or sudden jump while the peg turns can point to a binding nut.

If it continues. Inspect how the string is installed before replacing parts. A nut slot that needs cutting is a repair job.

Diagnose the nut · Check tuners and string winding

Several strings drift together

Check first. If you just changed strings or tuning, give the guitar another full tuning pass. If it came from a hotter or colder space, let it acclimate. On a floating bridge, watch whether tuning one string pulls the others off pitch.

If it continues. Check the bridge angle or the environment if the same pattern returns on later passes.

Floating bridge tuning · Temperature and humidity

Open strings are in tune but chords sound wrong

Check first. With the capo removed, tune the open string and compare it with the fretted note at the 12th fret using normal pressure. The fretted note should be an octave higher. Try lighter finger pressure before adjusting anything.

If it continues. If the sharp or flat result repeats, check intonation. If it happens only with a capo, check capo fit and pressure.

Measure the octave · Check intonation · Check capo placement

The guitar feels too loose or tight after retuning

Check first. Confirm your intended notes and octaves. Compare the old and new presets with the tension calculator while assuming you keep the current strings.

If it continues. If a lowered string rattles or wobbles under your usual attack, compare suitable gauges. Stop and look up instrument guidance if an upward tuning feels unusually tight.

Compare string tension · Choose a string gauge

Room noise overwhelms the tuner

Check first. Mute the other strings, bring the microphone closer, and move away from competing sound. If you can hear a reference tone clearly, try tuning by ear.

If it continues. For recurring noise, a clip-on can sense headstock vibration. A cable-connected tuner can help when your instrument has a suitable output.

Tuning in a noisy room · Compare clip-on and online tuners

Still unsure?

Note which string drifts, whether the tuner reading settles, and when the problem returns. Those details will help you narrow it down on the next tuning pass or describe it to a repair technician.
