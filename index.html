How to use this tuner

  1. Tap Start listening.
  2. Allow microphone access.
  3. Pluck one string at a time.
  4. If the tuner says flat, tighten the string.
  5. If the tuner says sharp, loosen the string.
  6. Stop when the meter is green and centered.

Free Online Guitar Tuner notes

This tuning uses the notes: E A D G B E, from the lowest thick string to the highest thin string.
