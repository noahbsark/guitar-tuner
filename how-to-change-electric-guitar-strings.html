How to Change Electric Guitar Strings

The basic process is simple, but the bridge type determines whether you should remove strings together or replace them one at a time.

Identify the bridge before starting

A fixed bridge stays in place when strings are removed. A floating tremolo balances string tension against springs, so removing every string can change its position. A locking tremolo adds a locking nut and fine tuners. If you are unsure which system you have, compare it with the instrument manual before loosening anything.

Tools and supplies

  • The correct electric-guitar string set
  • String winder and wire cutters
  • Soft cloth
  • Correct hex keys if the bridge or locking nut requires them
  • The online guitar tuner

Keep tools away from the finish and never use an ill-fitting wrench on bridge hardware.

Fixed-bridge method

  1. Loosen each old string until slack, then remove it from the post and bridge.
  2. Clean exposed areas with a finish-safe dry or lightly treated cloth.
  3. Feed each new string through the body, tailpiece, or bridge in the original direction.
  4. Pull it across the correct saddle and nut slot to the matching tuning post.
  5. Leave suitable slack and wind cleanly down the post.
  6. Bring all six strings gradually to pitch, then repeat the tuning pass.

Floating tremolo method

Replacing one string at a time helps preserve the bridge’s existing balance. Tune the replacement close to pitch before moving to the next string. After the entire set is changed, cycle through the strings repeatedly because every adjustment changes the pull on the bridge.

If you change gauge or tuning, the spring balance may require adjustment. This is a setup operation, not merely a string change. Avoid turning unfamiliar screws at random.

Locking tremolo method

Unlock the nut before making broad tuning changes. Many locking bridges clamp a trimmed string end at the saddle, while others accept the ball end according to their design. Center the bridge fine tuners before the final setup so they have adjustment range in both directions. Follow the specific bridge manufacturer’s instructions.

Never force a saddle block, locking screw, or fine tuner. Small specialized parts can strip or crack when overtightened.

Wind the post securely

For a conventional post, keep the wraps neat and descending. For a locking tuner, pull the string through, engage the lock using reasonable hand pressure, and use only the number of wraps the manufacturer recommends. More winding is not automatically more stable.

Stretch, tune, and check

Bring the guitar to its target tuning, gently settle each string, and retune. Repeat until pitch remains stable. Use moderate force; aggressive pulling can kink or break a string. Then test normal bends and, if present, light tremolo movement before checking again.

Set tuning and intonation separately

Open strings should first match the selected tuning. If the 12th-fret notes disagree afterward, check the intonation guide. A gauge change may require saddle adjustment even when the new open strings tune correctly.

Troubleshooting after restringing

  • One string slips: inspect its tuning-post lock or winding.
  • Pitch jumps with a ping: check for nut binding.
  • A floating bridge tilts: string and spring tension are out of balance.
  • Buzz appears: gauge, neck relief, or action may have changed.
  • Every string drifts: repeat the settling and tuning cycle.
