How to Use an Online Guitar Tuner

Tune accurately in a browser using the microphone already in your phone, tablet, or computer.

Quick answer: Open the tuner over HTTPS, choose the intended tuning, allow microphone access, pluck one string, and adjust until the correct note is centered.

Before starting

Confirm the six target notes before changing tension. Standard tuning is E A D G B E from the thick sixth string to the thin first. Alternate tunings change one or more targets, so selecting the correct preset prevents octave and note mistakes.

Microphone permission

The browser must receive permission to use the microphone. The tuner analyzes pitch locally and does not need to record a performance. If permission was denied previously, reopen the site settings beside the address bar and allow microphone access.

Reading the display

Flat means the string is below the target and must be tightened. Sharp means it is above the target and should be loosened. Confirm both the note name and the direction before turning a tuning key.

Step-by-step check

  1. Open the tuner and select the tuning preset.
  2. Tap Start listening and approve microphone access.
  3. Pluck the sixth string alone.
  4. Adjust slowly until its target note is centered.
  5. Repeat strings 5 through 1, then check all six again.

Reliable tuning habits

Work with one string at a time, use a moderate and repeatable picking attack, and let the initial pitch settle briefly. Make the final adjustment by approaching the target from below so slack is taken out of the tuning post and nut. After all six strings are close, repeat the entire pass because every tension change can slightly affect the other strings.
