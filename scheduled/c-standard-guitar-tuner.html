What is C Standard tuning?

C Standard keeps the same fourth-based interval pattern as E standard while lowering every string four semitones. Familiar chord and scale shapes still work, but everything sounds a major third lower than the shape name used in standard tuning.

How to tune from standard

  1. Lower the sixth string from E2 to C2.
  2. Lower the fifth string from A2 to F2.
  3. Lower the fourth string from D3 to Bb2.
  4. Lower the third string from G3 to Eb3.
  5. Lower the second string from B3 to G3.
  6. Lower the first string from E4 to C4, then repeat the tuning pass.
Setup note: The large pitch reduction makes ordinary light strings feel loose. A heavier, balanced set and a setup for C Standard will improve stability and intonation.

Sound and playing approach

Because every interval matches standard tuning, normal shapes and fingering relationships transfer directly. A familiar E-shape major chord sounds as C major at the open position, and the lower register adds weight without changing the basic fretboard geometry.

String gauges and setup

On a typical 25.5-inch scale, players commonly move several gauges heavier than a standard set. The ideal choice depends on tension preference and picking style. Recheck nut clearance, neck relief, action, and intonation after changing gauges.

How to get a stable reading

Use the neck pickup if your guitar has one, reduce background noise, and pluck one string gently near its center. Let the pitch settle before adjusting. Tune upward into each target pitch, then repeat all six strings because the neck and bridge respond as total tension changes.
