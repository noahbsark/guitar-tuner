Which Way Do You Turn Guitar Tuning Pegs?

There is no universal clockwise rule—the correct direction depends on the post, string winding, and which side of the headstock the tuner occupies.

The reliable rule

Watch the string where it wraps around the tuning post. Turn the key so the post pulls in more string to raise the pitch, or releases string to lower the pitch. This rule works on every guitar, regardless of headstock design.

Do not rely on “clockwise tightens.” Three-on-a-side, six-in-line, reverse-headstock, slotted, and classical tuners can appear to turn in different directions from the player’s viewpoint.

How to confirm the direction safely

  1. Pluck one string and identify its note with the online guitar tuner.
  2. Trace that string to the correct tuning post.
  3. Turn the key only a few degrees.
  4. Pluck again and watch whether the pitch moved higher or lower.
  5. Continue with small adjustments once the direction is confirmed.

If the note moved away from the target, reverse direction. A tiny test movement is safer and clearer than memorizing a rule that may not fit your instrument.

What “tighten” and “loosen” mean

Tightening increases string tension and raises pitch. Loosening reduces tension and lowers pitch. On the tuner display, a flat string needs to move upward; a sharp string needs to move downward.

Why headstock layouts cause confusion

Three tuners on each side

The bass-side and treble-side keys face opposite directions. A motion that looks clockwise from one side can look counterclockwise from the other, even though both posts are winding their strings correctly.

Six tuners in a row

All keys usually operate from the same side, so their visual direction is more consistent. Reverse headstocks and left-handed instruments can invert what a familiar diagram shows.

Classical and slotted headstocks

The roller sits horizontally through a slot instead of vertically through the headstock. The string path and viewing angle are different, so watch the roller and pitch rather than using an electric-guitar rule.

Approach the target from below

If you overshoot and become sharp, lower the pitch slightly below the target, then tighten upward again. Finishing from below helps take up slack between the post, nut, and bridge. It can improve stability when a string otherwise goes flat soon after tuning.

Avoid these mistakes

  • Turning the wrong key: trace the string visually before moving anything.
  • Making large turns: near the target, use very small movements.
  • Following only the note letter: make sure the string is in the correct octave.
  • Ignoring extreme tension: stop if a string feels unusually tight.
  • Forcing a stiff tuner: diagnose the cause instead of applying more force.

If the key turns but the pitch does not respond normally

The string may be slipping around the post, catching in the nut, or failing to seat at the bridge. A large dead zone can indicate backlash or worn gears. Follow the tuning peg troubleshooting guide before replacing hardware.

When installing a new string

Wind the string neatly in the direction intended by the headstock so it travels from the post toward the nut without an awkward sideways angle. After installation, gently settle it and retune. The guide to new-string tuning problems explains the full process.
