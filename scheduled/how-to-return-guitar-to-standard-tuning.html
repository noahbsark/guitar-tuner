How to Return a Guitar to Standard Tuning

Restore E A D G B E gradually, confirm every octave, and repeat the tuning pass.

Quick answer: Select the standard preset, bring all six strings near E2 A2 D3 G3 B3 E4, then make finer passes. Stop if a heavy string feels unusually tight.

Avoid octave mistakes

Note letters repeat in every octave. A tuner may display E even when the string is heading toward the wrong E. Use the frequency, neighboring strings, and normal tension as cross-checks.

Make a rough pass first

After a low alternate tuning, raising one string changes total neck and bridge tension. Bring every string close before perfecting any one target, then repeat with smaller corrections.

Watch floating bridges

A floating tremolo reacts strongly to total tension. Alternate across the strings and expect several rounds. If the bridge angle remains incorrect, spring balance may need adjustment.

How to choose

  1. Select Standard A440 on the tuner.
  2. Move each string gradually toward its target.
  3. Approach the final pitch from below.
  4. Repeat until all six remain stable.
  5. Check action and intonation if returning after a large gauge change.
