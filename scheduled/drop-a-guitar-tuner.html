What is Drop A tuning?

This six-string Drop A tuning uses A E A D F# B from low to high. It is B standard with the sixth string lowered another whole step. The result keeps standard-style intervals on the upper five strings and places a low A below them.

How to tune from standard

  1. Lower the sixth string from E2 to A1.
  2. Lower the fifth string from A2 to E2.
  3. Lower the fourth string from D3 to A2.
  4. Lower the third string from G3 to D3.
  5. Lower the second string from B3 to F#3.
  6. Lower the first string from E4 to B3, then recheck all six.
Setup note: Drop A is extremely low for a typical six-string. Use a suitable heavy set, adequate scale length, and a proper setup rather than forcing ordinary strings to perform at very low tension.

Sound and playing approach

The lowest three strings create A–E–A, producing a strong octave-and-fifth foundation for heavy riffs. The upper five strings behave like B standard, so scale and chord patterns can be adapted consistently once the whole fretboard is viewed seven semitones below standard.

String gauges and setup

A long scale or baritone-style instrument makes A1 clearer. Players often need a substantially heavier sixth string, and the nut may need widening. Check neck relief, bridge compensation, pickup height, and whether the string fits the tuner post safely.

How to get a stable reading

Use the neck pickup if your guitar has one, reduce background noise, and pluck one string gently near its center. Let the pitch settle before adjusting. Tune upward into each target pitch, then repeat all six strings because the neck and bridge respond as total tension changes.
