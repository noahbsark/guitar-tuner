What is B Standard tuning?

B Standard preserves standard tuning's intervals while moving every string down a perfect fourth. Chord and scale shapes remain familiar, but their sounding pitch is five semitones lower. It is common on baritone guitars and properly set-up extended-range six strings.

How to tune from standard

  1. Lower the sixth string from E2 to B1.
  2. Lower the fifth string from A2 to E2.
  3. Lower the fourth string from D3 to A2.
  4. Lower the third string from G3 to D3.
  5. Lower the second string from B3 to F#3.
  6. Lower the first string from E4 to B3, then recheck all strings.
Setup note: B Standard is far below a conventional six-string setup. Heavy strings, sufficient scale length, and correct nut and bridge adjustment are important for clear notes and reliable intonation.

Sound and playing approach

All standard-tuning patterns transfer because the interval layout is unchanged. The lower register provides a dark, broad sound for heavy rhythm guitar, while upper-string chord voicings remain easy to map using familiar shapes.

String gauges and setup

Baritone-scale instruments handle B Standard especially well. On a regular scale, heavier strings can restore tension but may require permanent nut-slot changes. Verify relief, action, intonation, pickup clearance, and tuning-machine compatibility.

How to get a stable reading

Use the neck pickup if your guitar has one, reduce background noise, and pluck one string gently near its center. Let the pitch settle before adjusting. Tune upward into each target pitch, then repeat all six strings because the neck and bridge respond as total tension changes.
