Can Pickup Height Affect Tuner Accuracy?

An extremely close magnetic pickup can pull a vibrating string and create unstable pitch.

Published by Online Guitar Tuner. How our guides are maintained · Report a correction

Quick answer: Yes, especially with strong magnetic pickups set very close to the strings. Lower the pickup if notes warble, sustain unevenly, or produce inconsistent tuner readings.

Magnetic pull

Magnetic pickups exert force on steel strings. When a pickup is too close, particularly beneath low strings near the neck position, it can alter vibration and create beating or pitch warble.

Signal strength versus accuracy

A stronger electrical signal is not automatically more accurate. The tuner needs a clean, stable waveform. Excessive magnetic influence, distortion, modulation, and noise can make detection worse.

Which pickup to use

The neck pickup often emphasizes the fundamental and works well for tuning, but it also sits where string motion is wide. With an electrical input, compare clean pickup signals and keep effects bypassed; changing the selector does not remove the magnets' physical pull.

Test before adjusting

Compare tuner behavior on different pickups and fret positions. Pickup height should also be balanced for tone and output, so make small measured changes rather than lowering everything blindly.

Inspection checklist

  1. Tune with a clean signal.
  2. Compare neck and bridge pickup readings.
  3. Listen for warbling on sustained fretted notes.
  4. Measure current pickup height before changing it.
  5. Lower in small equal steps and retest.

When to get professional help

Stop if a part is cracking, a string is binding under high tension, or an adjustment requires force. Nut work, major bridge changes, and truss-rod adjustments can affect playability permanently; a qualified repair technician can diagnose the instrument before material is removed or hardware is damaged.

Microphone input versus an electrical input

Changing the pickup selector changes the electrical signal sent to an amplifier or audio interface. It does not select the sound source for a phone's built-in microphone, and it does not remove the magnetic pull of the other pickups. With a microphone tuner, first check room noise and how clearly the open string reaches the microphone.

For a direct-input comparison, keep gain and effects consistent and record your starting pickup heights before moving anything. Use the model's measurement method with the appropriate fret held down. Fender's setup guidance explains that pickup type and position affect the appropriate clearance; one distance is not correct for every guitar.
