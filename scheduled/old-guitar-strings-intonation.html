How Old Strings Affect Guitar Intonation

Wear and contamination make a string vibrate less uniformly along its length.

Published by Online Guitar Tuner. How our guides are maintained · Report a correction

Quick answer: Old strings can tune correctly when open yet play inconsistently across the neck. Replace the set before making final saddle-intonation adjustments.

How strings age

Finger oils, corrosion, flattened windings, fret dents, and repeated bending change mass and flexibility along the string. The result may no longer behave like the uniform string assumed by the setup.

Typical symptoms

The tuner reading wavers, harmonics sound weak, a string feels rough or discolored, and fretted intonation changes unpredictably between positions. One string may behave much worse than the others.

Why not adjust around worn strings

Moving a saddle to compensate for a damaged string can make the guitar wrong for the replacement set. Intonation should be checked with fresh, stretched strings of the intended gauge.

Other causes to rule out

Poor nut slots, loose hardware, excessive pickup pull, and uneven fretting pressure can resemble old-string problems. Replace obviously worn strings first, then diagnose what remains.

Inspection checklist

  1. Inspect for corrosion, dents, and flat spots.
  2. Compare sustain and tuner stability across strings.
  3. Replace the full set with the intended gauge.
  4. Stretch and stabilize the new strings.
  5. Set intonation only after the new set holds pitch.

When to get professional help

Stop if a part is cracking, a string is binding under high tension, or an adjustment requires force. Nut work, major bridge changes, and truss-rod adjustments can affect playability permanently; a qualified repair technician can diagnose the instrument before material is removed or hardware is damaged.

Use a replacement set as a controlled comparison

If the old set is visibly worn, fit the same intended gauge and construction before changing saddle positions. Bring the new strings to stable pitch, then compare the same fretted notes using the same picking and fretting pressure. That separates a string change from a simultaneous geometry change.

For a complete octave check, use a full-range chromatic tuner; this site's open-string detector does not cover every 12th-fret target. Persistent errors with a settled new set need further diagnosis.
