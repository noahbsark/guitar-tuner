Alternate Guitar Tuning Cheat Sheet

Keep common six-string tuning notes in one low-to-high reference.

Quick answer: All sequences below run from the thick sixth string to the thin first string. Confirm the exact variant because some open tunings share names.

How to read the chart

The leftmost note is string 6 and the rightmost is string 1. Flats may also be written with enharmonic sharp names; for example, Eb and D# describe the same equal-tempered pitch class.

Check variants

Open C, Open A, and other names can refer to multiple sequences. Match all six notes to the lesson or song rather than relying on the tuning name alone.

Save string tension

Lowered tunings reduce tension on unchanged gauges. Tunings that raise strings need more caution. Consider a capo or lighter strings when several targets move upward.

How to choose

  1. Identify the exact six-note sequence.
  2. Select the matching tuner preset.
  3. Change strings slowly and confirm octaves.
  4. Write the tuning beside the song title.
  5. Return to standard with a complete six-string check.
