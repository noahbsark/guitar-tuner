Drop C vs C Standard Tuning

These tunings share a low C but organize the other five strings differently.

Quick answer: Drop C is C G C F A D and supports one-finger low power chords. C Standard is C F Bb Eb G C and preserves standard-tuning intervals across all six strings.

At-a-glance comparison

Fretboard relationships

Drop C is D Standard with the sixth string lowered one extra step. C Standard moves every standard string down four semitones, so scale and chord geometry remains unchanged.

String feel

Both are much lower than E Standard. Drop C often uses a heavier sixth string relative to the upper five; C Standard benefits from a consistently heavier balanced set.

Choosing for music

Drop C suits riffs centered on root–fifth–octave shapes across the lowest strings. C Standard is easier when you want familiar chord shapes sounding a major third lower.

How to choose

  1. Choose based on interval layout, not only the lowest note.
  2. Use Drop C for barred bass power chords.
  3. Use C Standard when standard shapes should transfer directly.
  4. Plan a setup if the tuning is permanent.
