Microphone Not Working with an Online Guitar Tuner

Restore browser microphone access and give the tuner a clear guitar signal.

Quick answer: Use the HTTPS website, allow microphone access in the browser and operating system, close apps holding the microphone, then reload and tap Start again.

Browser permission

Select the lock or site-settings icon near the address bar and set Microphone to Allow. If the site was blocked earlier, changing the permission may require a reload before the browser creates a new audio session.

Operating-system privacy settings

Phones and computers can deny microphone access to the entire browser. Open system privacy settings, enable the microphone for the browser, and confirm that the intended input device is selected.

Permission works but no pitch appears

Move closer, raise an electric guitar's volume control, choose a clean pickup signal, and pluck one string clearly. Bluetooth headsets and audio-routing software can select an unexpected microphone.

Step-by-step check

  1. Confirm the URL begins with https://.
  2. Tap Start listening to trigger the permission request.
  3. Allow microphone access for the site and browser.
  4. Reload the page after changing settings.
  5. Test another browser or input device if no level appears.

Reliable tuning habits

Work with one string at a time, use a moderate and repeatable picking attack, and let the initial pitch settle briefly. Make the final adjustment by approaching the target from below so slack is taken out of the tuning post and nut. After all six strings are close, repeat the entire pass because every tension change can slightly affect the other strings.

Use the input-level bar as a diagnostic

After the status changes to Listening, pluck a string and watch the small level bar. No movement suggests the wrong input, an operating-system block, or a muted microphone. Movement without a stable note usually points to low volume, room noise, Bluetooth routing, or an unclear signal. This distinction helps you decide whether to change permissions or improve how the guitar reaches the microphone.
