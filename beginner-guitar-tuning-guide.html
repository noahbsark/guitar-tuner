How to Tune a Guitar for Beginners

A simple guide to tuning your guitar using the built-in microphone tuner.

Published by Online Guitar Tuner. How our guides are maintained · Report a correction

Standard guitar tuning

Standard guitar tuning, from the lowest thick string to the highest thin string, is E A D G B E.

Before you start

  • Move to a reasonably quiet room and mute the strings you are not tuning.
  • Confirm that the selected preset matches the tuning you want.
  • Identify string 6 as the thick low string and string 1 as the thin high string.
  • Use small tuning-key movements and stop if a string feels unusually tight.

Step-by-step tuning

  1. Open the free guitar tuner.
  2. Choose your tuning from the dropdown.
  3. Tap Start listening and allow microphone access.
  4. Pluck one string clearly.
  5. If the note is flat, tighten the string slowly.
  6. If the note is sharp, loosen the string slowly.
  7. Repeat for each string.

What flat and sharp mean

Flat means the string is too low. Tune up by tightening the string. Sharp means the string is too high. Tune down by loosening the string.

Tune in more than one pass

Changing one string slightly changes the total tension on the guitar, especially on instruments with floating tremolo bridges. Tune all six strings once, then return to the low string and check them again. Pluck with moderate force and judge the pitch after the sharp initial attack settles.

Check the octave as well as the note letter. Standard guitar targets are E2, A2, D3, G3, B3, and E4. If a heavy string feels very tight or a thin string feels extremely loose, stop and confirm the intended octave before continuing.

Why your guitar may still sound out of tune

  • Old strings can drift or sound dull.
  • New strings need to stretch.
  • Pressing too hard on the frets can make notes sharp.
  • The guitar may need intonation adjustment.

Match the string before turning a peg

The two E strings have the same letter but are two octaves apart. Use thickness and position to identify them; do not try to tighten the thick E string until it reaches the thin E string's pitch.

A complete example: tuning the A string

  1. Select Standard and pluck string 5, with the other strings muted.
  2. Confirm the intended target is A2. The tuner compares sound with the selected preset; it is not a full-range chromatic note identifier.
  3. If the settled reading is −12 cents, make a small adjustment upward. Pluck again before making another adjustment.
  4. If you pass the target and read +8 cents, loosen below the target and approach upward again.
  5. Finish near the center, then revisit the string after tuning the other five.

These readings illustrate the process; they are not measurements from a particular guitar. If the string is far from its target, a preset tuner may show another string or no stable reading. Compare with a known reference or a chromatic tuner before making a large adjustment.

Before your first song

Play a familiar chord gently, check each open string once more, and remove a capo if you used one. If open strings are stable but fretted chords remain sharp, investigate intonation and fretting pressure rather than repeatedly retuning the open strings.
