What is Double Drop D?

Double Drop D uses D A D G B D. It starts with standard tuning and lowers both E strings by one whole step to D. The middle four strings stay at A, D, G, and B. The two outside D strings can frame chords and melodies with ringing octave drones.

How to tune from standard

  1. Lower the sixth string from E2 to D2.
  2. Leave strings 5 through 2 at A2, D3, G3, and B3.
  3. Lower the first string from E4 to D4.
  4. Recheck both lowered strings after playing for a minute.

How it differs from Drop D

Drop D changes only the low sixth string. Double Drop D also lowers the high first string, creating a D drone on both edges of the guitar. Standard shapes that use the first string may need adjustment, while shapes limited to strings 5 through 2 remain familiar.

Playing and setup tips

  • Use the open first string as a melody drone in arrangements centered on D.
  • Check whether a standard chord contains an unwanted high D before letting the first string ring.
  • A normal string set usually works without a setup change.
  • To return to standard, raise strings 6 and 1 from D to E.
