Record two pitches

  1. Bring the string to pitch, remove any capo, and mute the other strings.
  2. Start listening, pluck the open string and wait for a steady reading. Select Record open string.
  3. Fret the same string at the 12th fret with normal playing pressure and pluck it. Select Record 12th fret when its reading settles.

What the reading means

The expected 12th-fret pitch is twice the measured open-string frequency. A note above it reads sharp; a note below it reads flat. The checker asks you to try again if the result is more than a semitone from that octave.

Repeat the test with a similar attack and normal fretting pressure. A worn string, a hard press, or an unstable recording can skew the result. The checker cannot distinguish a fretted note from an octave harmonic, so be sure to press the string to the fret.

If the result repeats, the guitar intonation guide explains what to check before adjusting. Consult Fender’s intonation instructions for an example of a manufacturer procedure.
