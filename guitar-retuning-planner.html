Use the plan

Use the custom tuner for notes outside the preset list.

Start at string 6, the thickest string. Read the target note and octave together. Move in small steps, recheck each string afterward, and repeat the full pass if your bridge floats.

Some presets share the same note names while changing the reference pitch. If the table shows cents instead of semitones, use the target frequency or the preset tuner to confirm the smaller change.

If the plan raises several strings, compare the tension change and check the guitar and string maker’s guidance first. For Open E, Open D with capo 2 gives the same sounding pitches with the guitar tuned to Open D underneath.
