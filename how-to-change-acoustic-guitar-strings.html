How to Change Acoustic Guitar Strings

A careful restring prevents slipping, protects the bridge and finish, and helps a new set reach stable tuning faster.

What you need

  • A string set appropriate for your guitar
  • A string winder, optional but helpful
  • Wire cutters
  • A bridge-pin puller or a winder with a built-in puller
  • A soft cloth
  • The online guitar tuner

Check the manufacturer’s recommended string gauge before changing it. A large gauge change can affect nut fit, neck relief, action, and intonation.

Should you remove every string at once?

For a healthy fixed-bridge acoustic, removing all six strings is normally useful when cleaning the fretboard. Changing one at a time is also acceptable and keeps tension more constant. If the guitar has unusual hardware, an undersaddle component that can move, or a known structural problem, follow its manufacturer’s procedure or ask a technician.

1. Loosen and remove the old strings

Turn each tuner until the string is slack before cutting or unwinding it. Remove the string from the post. Use a bridge-pin puller to lift the pin straight upward; avoid prying against the guitar top with pliers or cutters.

2. Clean accessible areas

With the strings removed, wipe dust from the headstock, fretboard, bridge, and body using products suitable for the instrument’s finish and fretboard material. Do not saturate wood or allow liquid into hardware.

3. Seat the ball end correctly

  1. Insert the string’s ball end into the bridge hole.
  2. Place the bridge pin in its matching orientation without forcing it.
  3. Pull the string gently upward while holding the pin so the ball seats against the bridge plate inside the guitar.
  4. Confirm the pin remains secure as tension begins to rise.
The bridge pin should retain the seated string; it should not carry all the pulling force at its pointed tip. Never hammer a pin into place.

4. Wind the tuning post neatly

Thread the string through the correct post and leave enough slack for a few orderly wraps. Turn the key so the wraps descend down the post without crossing. The string should leave the post toward the nut cleanly. Hold light tension with your other hand so the winding stays controlled.

Too little wrap can slip, while excessive or overlapping wrap takes longer to settle. Follow the tuning-machine maker’s procedure when using locking tuners or an unusual post design.

5. Bring the set to pitch gradually

Tune toward standard E A D G B E in stages rather than taking one string to full pitch while every other string is loose. Make a second pass after all six are close. If the guitar uses another tuning, select that target only after confirming the gauge and setup support it.

6. Settle and retune

Gently lift each string at several points along its length, then retune. The goal is to remove installation slack, not to pull hard. Repeat until another gentle pass causes little pitch loss. If the pitch keeps dropping, review why new guitar strings go out of tune and check the windings and bridge seating.

Trim and inspect

Once the windings are secure and the guitar holds pitch, trim excess string close enough to avoid sharp ends without cutting into the wrap. Check that every bridge pin remains seated, every string follows the nut slot, and no wrap overlaps another.

Common mistakes

  • Pulling bridge pins sideways with metal tools
  • Leaving the ball end hanging from the bottom of the pin
  • Crossing or piling up tuning-post wraps
  • Cutting a string before confirming its final path
  • Tuning the wrong string or wrong octave
  • Installing a gauge the nut cannot accept
