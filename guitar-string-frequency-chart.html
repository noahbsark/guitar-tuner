Frequency is the number of sound-wave cycles per second, measured in hertz (Hz). These targets use twelve-tone equal temperament and A4 = 440 Hz unless a table says otherwise. Values are rounded to two decimal places; the live tuner uses more precise numbers internally.

Why a tuner may show a moving frequency

A plucked string is not perfectly steady. The initial attack can read slightly sharp, then the pitch settles as the sound decays. Pick with moderate force, avoid touching neighboring strings, and judge the stable portion of the note. Old strings, fret pressure, room noise, and poor intonation can also cause movement.

Reference pitch changes

The 432 Hz tuner lowers all standard-tuning targets by the ratio 432/440. The 528 Hz preset defines C5 as 528 Hz, making A4 approximately 443.993 Hz. Do not mix reference calibrations within one instrument or ensemble.

Use the chart correctly

  • String 6 is the thickest, lowest-pitched string.
  • String 1 is the thinnest, highest-pitched string.
  • Hz values identify pitch, not recommended string tension.
  • Choose a string gauge and setup appropriate for the target tuning.
