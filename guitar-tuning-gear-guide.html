Clip-on or connected tuner

Check whether the current setup gives repeatable readings before buying hardware.

Before buying a clip-on for a silent input meter, check which microphone the browser is using. For recurring background noise, a clip-on may still help.

A clip-on senses vibration at the headstock and can be useful when a microphone hears the room. For an electric guitar on stage, a cable-connected tuner gives you a more direct signal. Check the note range for baritone and seven-string guitars.

Replacement strings

For dropped tunings, decide whether to keep the set, change a single string, or choose a heavier set.

If your current set feels right, start by matching its gauge and string type. When changing tuning, compare tension on your current strings before buying a new set. Check the gauge guide or the 12-string guide for a different setup.

Capo fit and pressure

Check whether a capo gets you to the song key with shapes you already know.

Check which strings need to move before deciding whether a capo is useful.

If notes ring cleanly and stay in tune with your current capo, keep using it. If notes go sharp, place it just behind the fret and ease the pressure. For a replacement, check neck width and whether the capo matches a flat or curved fretboard.

Maintenance tools

If open strings are in tune but fretted notes sound off, measure the octave before buying setup tools.

Start by observing what moves. Pinging beside the nut suggests binding, repeated pitch drops on one string suggest slipping, and slow changes across strings may reflect the environment. A hygrometer can help you check humidity before purchasing humidity controls.
