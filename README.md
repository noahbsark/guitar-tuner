# Simple Guitar Tuner Website

This is a GitHub Pages-ready static website for a free browser-based guitar tuner.

## Files

- `index.html` — main free guitar tuner page
- `drop-d-guitar-tuner.html` — Drop D landing page
- `dadgad-guitar-tuner.html` — DADGAD landing page
- `open-g-guitar-tuner.html` — Open G landing page
- `open-d-guitar-tuner.html` — Open D landing page
- `open-e-guitar-tuner.html` — Open E landing page
- `half-step-down-guitar-tuner.html` — half step down landing page
- `whole-step-down-guitar-tuner.html` — whole step down landing page
- `432-hz-guitar-tuner.html` — standard tuning calibrated to A4 = 432 Hz
- `528-hz-guitar-tuner.html` — standard tuning with C5 = 528 Hz (A4 ≈ 444 Hz)
- `beginner-guitar-tuning-guide.html` — beginner SEO guide
- `about.html`, `privacy.html`, `contact.html`
- `styles.css` — shared styling
- `tuner.js` — shared tuner logic
- `robots.txt`, `sitemap.xml`

## Publish on GitHub Pages

1. Create a new public GitHub repository.
2. Upload all files in this folder to the root of the repo.
3. Go to Settings → Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/root`.
6. Save.
7. Open the Pages URL on your phone and test microphone access.

## Before launch

- Replace the placeholder email in `contact.html`.
- Replace `https://example.com` in `sitemap.xml` and `robots.txt` with your real domain.
- Add your custom domain in GitHub Pages settings if you buy one.
- Test microphone permission on iPhone Safari and Android Chrome.
- Update `privacy.html` if you add analytics, ads, or affiliate links.
